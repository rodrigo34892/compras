# 🛒 CLI Shopping Cart with Rich Terminal Interface

> [!NOTE]
> ⏳ **Nota de Contexto:** Este é um projetinho que desenvolvi há algum tempo durante os meus estudos de Python e POO, e que estava guardado no meu computador. Estou subindo e documentando ele agora para manter meu portfólio organizado!

---

### 📝 Descrição do Projeto

> Um sistema interativo de carrinho de compras desenvolvido em Python, focado no uso prático de **Orientação a Objetos (POO)** e com uma interface de linha de comando (CLI) estilizada através da biblioteca `Rich`.

---

## 🚀 Funcionalidades Principais

| Recurso | Aplicação Prática no Código |
| :--- | :--- |
| **🔗 Relação entre Objetos** | Associação dinâmica entre a classe `CarrinhoDeCompras` e instâncias da classe `Produto`. |
| **🛡️ Tratamento de Exceções** | Sistema protegido com blocos `try/except ValueError` para validar entradas, garantindo estabilidade. |
| **🎨 Interface Rica (UX/CLI)** | Uso da biblioteca `Rich` para renderizar cores e painéis (`Panel`) direto no terminal. |
| **🔍 Busca Inteligente** | Tratamento de strings com `.strip().lower()` para mitigar erros de digitação ao buscar itens. |

---

## 🛠️ Tecnologias Utilizadas

* **Python** (Linguagem principal do ecossistema)
* **Rich Library** (Estilização de alto nível para interfaces CLI)
